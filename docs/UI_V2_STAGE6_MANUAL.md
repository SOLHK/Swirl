# Swirl 0.2.6 UI V2.1 人工检查

本版本按诊断版交付。先检查界面和来源管理；实际代理切换按你的现有工作环境安排，受控自动测试不代替私人节点和真实服务验收。

1. 打开程序，核对版本 0.2.6。检查中性灰白底、稍深侧栏、窗口和侧栏 14dp 圆角。调整窗口尺寸、最大化再恢复；原导航入口和活动页主要布局应保留。
2. 节点页搜索、筛选、组内排序，折叠/展开来源，查看详情、收藏和测速。浏览节点不能改变策略出口；测速失败应保留真实错误，不显示虚假成功延迟。
3. 策略页检查“服务分配｜策略组”、永久默认策略及来源删除后的失效出口。打开选择器，修改后等待实际回执；停机只表示保存到下次连接。应用进程识别/TUN 当前不可用。
4. 订阅页检查紧凑来源行、名称搜索、失败/自动更新筛选、单项更新和更多操作。添加来源默认自动识别；客户端格式位于高级设置。编辑地址留空应保留原加密地址；更新失败保留上次节点。
5. 对有完整配置缓存的来源打开“审阅完整配置”。先核对替换影响；取消不能改变现有路由。“本次应用”只授权一次，来源/配置变化或超过 10 分钟后须重新审阅。旧缓存没有原始响应身份时，会要求你手动更新，不自动重新下载。
6. 删除来源先阅读节点数量和策略影响。取消保留来源；确认成功后所属节点移除，引用出口显示失效，不能自动改为 DIRECT。
7. 活动页直接点击“规则分流”灰色胶囊，选择规则分流、全局代理或直连；外观与“事件”一致，没有蓝框或旁边额外按钮。Esc 关闭并回到原控件；事务未完成前显示旧模式。停机保存的“下次连接生效”说明位于菜单和提示中。
8. 连续快速切页、反向展开、打开/关闭弹窗；检查文字清晰、焦点不丢失。开启减少动态效果后重复操作，功能和最终状态应相同。

100%、125%、150%、175%、200% 的人工视觉验收由你负责。若遇到问题，记录版本、页面、操作顺序、显示缩放、主题和截图；不要把订阅地址、节点凭据或解密缓存放进公共 issue。
