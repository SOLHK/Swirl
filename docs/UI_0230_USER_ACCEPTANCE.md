# Swirl 0.2.30：五绳分镜及共享界面样式

基于 18e63333aabb59f7d21326a15a92a798baa4466c，在 work/swirl-activity-details-20261030 开发。
这份清单是交给用户操作的验收方法，不是测试通过记录。没有运行应用、安装验收、自动化测试、录屏或截图。
本轮提供构建及打包产物，实际运行、DPI、动效、性能与交互仍未验证；编译结果以随包交付报告为准。

## 改动及空间设计

五卡位置与比例沿用上一版。主内容区统一持有绳子状态，整段正向 1900ms、反向 1100ms。
每根绳的行进路线和结内曲线合并为一条连续路径，端头沿弧长前进，尾端跟进并收进结内；
不会在汇合点替换静态图片。尾部收束上限由几何长度决定，避免长绳一直连接五张卡。
同一进度反向回放当前几何，不清零重启。离开页面按真实状态收尾；详情期间暂停，返回继续。

| 卡片 / 颜色 | 出场及路线 | 时间（约） |
| --- | --- | --- |
| 活动连接 / 暖橙 | 上沿偏左，先抬升，绕到右侧辅助区左边，沿两排之间的空隙靠近 | 0ms 出发，1121ms 汇入 |
| 网络诊断 / 珊瑚红 | 左侧中段向外舒展，再收拢进入中间留白 | 38ms 出发，1045ms 汇入 |
| 流量来源 / 柔紫 | 上沿偏右轻抬，跨过排间空隙后向品牌区下侧汇入 | 76ms 出发，931ms 汇入 |
| 传输 / 湖绿 | 左下侧边缘侧滑，转向连接卡右侧留白 | 152ms 出发，817ms 汇入 |
| 连接状态 / 青蓝 | 品牌预留区内先舒展小弧，较早开始局部云卷 | 304ms 出发，589ms 开始盘绕 |

路径取实际卡片坐标和品牌预留区，不使用屏幕物理宽度。每个出场点有不同的短弧姿态，
长路线经过卡片时画在实心卡面背后；出场留白和祥云结预留区才画在前面。
三个绘制视图共享同一条路径、同一首尾进度，所以遮挡不会改变绳子的空间位置。
各绳在接入点使用方向相接的三次曲线，时间曲线使用连续速度的分段 Hermite 插值。
先到先盘绕，四处交叉由局部下穿留隙和上穿段重绘表示；完成后停止变化。
纯色、圆端、等粗线条取代纤维、渐变高光和旧引线组件。

羽翼改为共同舒展方向的五片圆缓弧形羽片。删除中轴和羽脉绘制，用轮廓、间距和叠色区分层次。
主要构图收在左下，右上小范围呼应；主窗口和二级窗口复用背景组件。

Theme.shapeCorner 为共享连续曲率的尺寸基准：卡片、侧栏、窗口使用 28dp，弹层取约 22dp；
胶囊按自身半高取圆角。窗口 GPU 边缘、软件区裁切与阴影仍使用既有 2.5 次幂轮廓，
原生弹层裁切原先默认圆弧已改成同一曲率。卡片表面组件提为 SwirlCardSurface，被详情、菜单、
组合框和对话框共用。侧栏内部依旧清透，不额外铺白底。

顶部四项共用 SwirlToolbarButton，30dp 高、16dp 横向留白、中性灰平面底，不缩放、不抬升。
状态点和文字表达状态；代理开关接入原有逻辑。规则选择三项纵排，轻浅品牌选中底与小对勾，
取消原亮蓝色块和层层胶囊。规则状态和不可用原因在面板底部可读，错误仍由既有页面/操作反馈显示。
展开与收起复用可反向弹层进度，箭头跟同一进度变化，保留外部点击和 Esc 关闭。

活动卡片点击不产生描边、下划线、说明气泡或额外按压提示，只进入原有详情转场。
普通 Hover 仍有轻量反馈。按钮气泡从基础控件与页面内嵌入口删除，图标说明保留为无障碍元数据。
非按钮的图表采样值、表格长文本、策略运行详情等数据提示保留。

## 你自己检查

1. 退出托盘里的旧 Swirl，安装本轮 0.2.30。确认侧栏/关于页显示新版本。旧 0.2.29 安装包没有本轮改动。
2. 先保持代理关闭。看五张卡片排列是否不变、背景是否是没有叶脉的羽片、左下和右上的主次是否清楚。
3. 对比软件外角、侧栏、卡片、菜单：转角过渡是否协调，有没有裁切缺口、接缝、白边或黑色轮廓。
4. 点五张卡各一次再按 Esc 返回。点击和返回时不能多出紫边、下划线或提示，仍应连续回到原卡位置。
5. 开启代理，按上表看五根绳来自哪里。先看到短弧，再看到短绳移动，连接卡先盘出云卷，其他颜色依次穿入。
6. 看约 1.9 秒的全过程：不能像五根长加载条，不能掠过数值、图表和按钮；背后遮挡前后应合理衔接，最终只留祥云结。
7. 在出场、途中、编结将结束时各关闭一次，再立即开启。应从当前画面反向或继续，没有完整图标闪现或残线。
8. 成结后等待数据刷新，多次切详情/返回，不应重新触发整段编织。编织中打开详情再返回，检查是否接着原位置继续。
9. 编织时拖动窗口边缘、收起/展开侧栏、滚动窄窗口。锚点应跟着卡片，绳子不抢点击或滚轮。
10. Windows 缩放分别试 100%、125%、150%、175%、200%；先最大化，再试约 1520 物理像素宽。
    150% 重点核对双列五卡。175%/200% 的同一物理宽度可能低于原 736dp 内容断点，放大窗口应恢复双列。
11. 如果有多台屏幕，把窗口跨不同 DPI 显示器拖动；观察曲线粗细、锚点和外角。不具备第二屏就记录未验证。
12. 对比顶部事件、系统代理、TUN、规则分流：同高、同底色、同字体，图标和文字居中，无凸起渐变、边框或悬停放大。
13. 反复展开规则选择，快速开关，点面板外和按 Esc。看箭头与面板同步，面板不出窗口边界。
14. 三种规则模式各试一次；确认标记跟随真正成功的模式，禁用原因在面板中可读，失败仍有操作反馈。
15. 鼠标在系统代理、TUN、规则分流、更换出口、图标按钮、侧栏、窗口按钮、关于页链接按钮上各停留 3 秒。
    均不应弹按钮说明。图表数据点、表格长文本等非按钮数据提示允许存在。
16. 用 Tab、Enter、Space、Esc 操作，确认键盘仍可使用；再看深色、增强对比和减少动态效果。
