# 0.2.7 订阅界面重构

接续 0.2.6 UI V2.1。用户明确否定刚交付的订阅界面，尤其是刷新等控件的陈旧观感；本次改变页面的信息层级、操作入口和表单组织。继续使用 `work/swirl-ui-v2-20261024`，不修改 main。安装包与最终同提交 CI 状态以独立交付记录为准。

## 设计与实现

用 Hallmark 的既有产品屏幕约束、UI UX Pro Max 的渐进披露与键盘操作、Motion 的状态反馈和 Qt QML 的原生组件实现。沿用已确认的灰白材质、字体、窗口与侧栏尺寸、14dp 轮廓；不增加网页框架或新的依赖。

- 页面改为来源、节点、最近更新、行尾操作对齐的紧凑清单。来源身份使用静态 layers 图标，与更新动作明确区分。原 subscriptions 与 refresh 资源路径完全相同，是旧界面重复循环箭头的原因之一。
- 新增订阅局部使用的 SubscriptionAction 和两个单色 SVG。刷新使用单向回转图形，更多使用正式省略号资源，两者有稳定位置和 44dp 命中区。添加为低对比实体按钮，其余为安静操作；没有立体阴影或渐变。原有 checkmark.svg 实际是四宫格占位，已修正为真正的勾选图形。
- 筛选由上下箭头下拉框改为三段选择；搜索保留标准查找快捷键。行内只保留更新／取消与更多。编辑、查看节点、完整配置审阅和删除统一在菜单，删除单独分组。展开区仅显示更新事实、真实失败和说明，不再复制操作条或通用声明。
- 完整操作信息压为页脚单行，显式打开可选择、滚动的详情。模态详情打开期间禁用背后的查找快捷键。没有丢弃后端错误或回执信息。
- 添加／编辑表单分为来源和更新两组；频率和自动更新开关同行，格式偏好在高级设置中。密码显示、敏感输入、关闭后清空地址、留空保留密文、未保存草稿保护均保留。
- 订阅局部按钮、菜单、字段和开关使用中性焦点表达；鼠标点击不留下蓝框，Tab／反向 Tab／快捷键仍有可见轮廓。复用已有短悬停、按压、菜单和展开时钟；减少动态效果直接到终态。旋转仅反映真实正在更新，取消仍可在全页忙碌时使用。

## 行为边界

未改动节点导入、自动更新、完整配置审阅或 Rust 事务实现。保存／删除／本次应用仍等待对应 request_id 的真实回执；提交失败保留草稿，恢复操作和在途关闭锁保持原样。自动更新只处理来源节点；完整配置必须显式审阅和单次确认，不会获得以后自动更新的配置授权。keyed delegate 与池化清理、来源身份和展开状态保持。

没有重下载私人订阅，没有改变本机代理、TUN、路由、DNS或已有安装。原生验证使用临时加密存储和受控 HTTPS 来源。实际供应商联网、Codex 服务、TUN、全部 DPI／多屏和主观观感继续独立验收。

## 验证与交付

本次验证记录保存在忽略目录 `work/subscription-v027/`。源码边界和 7 项 portable boundary 已通过。最终五个 QML 文件的 Qt 类型检查无诊断。确定性 QML 扫描保留项目属性顺序、var模型、透明边框等风格建议，没有把建议计为通过。六个独立审查任务覆盖绑定、布局、加载生命周期、模型池化、状态动效、渲染性能；修正了操作详情模态框未保护查找快捷键的问题。

原生节点 UI 检查新增最小窗口标题可读宽度、行尾操作命中区／边界／不重叠，以及清单、菜单、编辑弹窗截图。原有受控 HTTPS 真正刷新、密文地址保留、失败保留节点、只读配置审阅、取消与删除回执断言保持。U2 表单检查先展开高级设置再检查七种格式、滚动、弹层边界与草稿保护，适应新的渐进披露。最终原生结果、版本和包摘要以交付记录为准，不由本文推定。

首轮原生节点 UI 606/0，进程退出 0。表单专项首轮发现两个失败：测试将 QT_SCALE_FACTOR 误当完整 DPR（本机系统缩放 1.5，进程系数 1.5，实际 DPR=2.25）；以及新格式项固定高度使文字内容高于可用高度。测试支持明确的 SWIRL_EXPECTED_DPR 并记录预期与实际值，未设置时兼容原逻辑；产品格式项改为按内容和上下内边距计算最小高度。严格文字裁剪断言保留。失败报告和图像保留，不能计为最终通过。

修正后的提交前检查：`native-final` 606/0，`u2-form-final` 38/0，两进程退出 0、标准错误为空、未触发 QML 警告。表单实测 DPR=2.25，最后格式项文字高18、可用高26、行高34；这是代表性高缩放验证，不是全 DPI 矩阵。最终清单、更多菜单、编辑与失败截图已实际查看；提示框改为局部中性样式，菜单打开时不出现悬停提示。窗口／侧栏源码边界和 portable 7/7 通过。最终包仍由同提交生产 CI 独立验证。
