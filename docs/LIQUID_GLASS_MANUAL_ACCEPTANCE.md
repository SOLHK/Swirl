# Swirl 0.1.8 人工验收步骤

状态：等待你验收。编译和预览启动/关闭检查通过，不代表视觉、性能或真实网络功能验收通过。

## 1. 启动这一版

1. 解压 `Swirl-0.1.8-LiquidGlass-preview.zip`，不要直接在压缩包内运行。
2. 双击 `Start-Preview.cmd`。
3. 确认侧栏显示 `Swirl Core · v0.1.8`，右上角是 `— / □ / ×`，左上角没有红黄绿按钮。
4. 这个入口使用临时数据和隔离设置，不会激活或替换已安装版本。节点、订阅、流量为空是预期情况；关闭后无需保留临时数据。请通过此入口进行本轮 UI 验收。

## 2. 必须先验收 150% DPI

Windows 设置 → 系统 → 屏幕 → 缩放 → 150%。关闭预览后重新通过 `Start-Preview.cmd` 启动。
先保持默认窗口大小，不要最大化，主题切到浅色。

逐项检查：

- 侧栏：玻璃应透出 Swirl 内部延展到下方的背景和内容，不应额外铺白色或灰色底。切换活动、概览等内容时，观察玻璃下方是否随内容变化；右侧和下方仅保留柔和投影。
- 顶部：事件、系统代理、TUN 胶囊应为可辨认的中性灰白按钮。点击系统代理应直接进入更多中的节点管理，不再弹出状态小窗口。
- 两张大卡片：大小、位置和高度是否保持原样；四角、底边是否有白边、双边、锯齿或被截断的阴影。
- 下方三个模块：仍然没有大型背景卡片；必要分隔线应细而自然，不发白光。
- 全部/仅代理、来源分类、今日/本月：连续切换，选中块应在控件内部移动，不出现双重描边、残影或错位。

## 3. Windows 窗口操作

1. 点击最大化：窗口填满工作区，任务栏仍保留；图标变为还原。
2. 点击还原：回到之前的窗口大小。
3. 点击最小化，再从任务栏恢复：界面不空白，按钮仍正常。
4. 在标题空白区域双击：最大化/还原各试一次。
5. 拖动窗口及拖动边缘调整大小：文字和控件不能脱离位置。
6. 最后点击关闭：本验收窗口正常退出。

说明：按钮由 Qt 绘制，使用 Windows 的排列和窗口操作语义；不是系统原生绘制的标题栏。本版没有新增“悬停最大化按钮弹出 Snap Layout”能力。

## 4. 浅色、深色与动效

入口：更多 → 设置 → 常规。

- 用鼠标依次选择深色、浅色、跟随系统，再循环两次；选择后菜单应关闭，其他开关仍能点击。切换主题时，两张活动卡片不能变形、跳位。
- 按 Apple Music 参考图的方向判断侧栏层次：轮廓完整、柔和投影、材质与内容背景分离。重点看是否“浮起来”，不是看是否足够白或透明。
- 快速点击活动/概览/更多来回切换十次，中途改点另一页。最终页面应正确，旧页面和选中背景不能残留。
- 悬停、按住和松开普通按钮：反馈应短促克制，不持续弹跳、不放大整张内容卡片。
- 打开节点添加、订阅添加和下拉菜单；按 Esc 关闭，焦点应正常返回。不要保存测试内容即可。
- 打开“减少动画”：页面和选中状态仍可操作，装饰动画减少。
- 关闭“磨砂背景”、打开“增强对比度”：文字、状态和键盘焦点仍能辨认。

## 5. 其他页面及缩放

在同一主题和窗口尺寸下，依次查看：概览、进程、设备、策略、规则、捕获、解密、重写、更多、面板、设置、节点、订阅、网络诊断。
检查活动连接、流量分析的操作区与窗口按钮是否分开；捕获、重写的最后一张卡片应铺满尾行，解密左右卡片的底部应对齐。更多页应没有重复的字体卡片，字体从通用设置进入。标注“研发中”或尚未满足证书等前置条件的控件仍保留禁用，不算点击失效。

150% 完成后，再看 100%、125%、175%、200%。每次缩放后重启预览，重点复查侧栏右边、卡片四角、胶囊和窗口按钮。最后恢复你平时使用的缩放。

- 主题：浅色/深色

你确认之前，本轮最终视觉验收始终是“待验收”。这个隔离预览不用于证明已有私人节点、系统代理/TUN 或跨平台 Rust Core 的真实网络可用性。
