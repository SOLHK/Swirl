普通浅色卡面为不透明 `#FFFFFF`，背景、侧边栏、羽翼与全局 Theme 不改。
继续使用原有 2.5 次幂连续曲率和抗锯齿表面；外卡半径仍为 28dp，分组控件使用 10dp，
28dp 高的时间胶囊使用 14dp。复用现有阴影着色器，扩散参数从 3dp 调整为 8dp、偏移 3dp、
浅色基准不透明度 6.5%，按下时收紧。它是淡接触阴影，不增加玻璃层或发光边框。
键盘焦点与用户主动开启的增强对比仍保留清楚的边界；深色模式沿用现有深色实心表面。

引线颜色：连接状态青蓝、传输湖绿、流量来源柔紫、网络诊断珊瑚红、活动连接暖橙。
路径用 `mapToItem()` 得到的卡片和品牌区域坐标生成，宽屏沿卡片间隙，紧凑布局沿外侧留白。
四段 `PathCubic` 对象保持常驻；动画帧只改变裁切和少量控制点，不逐帧创建 QML 对象或拼接 SVG。
几何表只在布局、窗口尺寸、UI 缩放或 Hover 位移变化时更新。路径属于主内容层，不受单张卡片裁剪。

总时长从 4800ms 减到 4100ms，缩短约 14.6%。五根绳约错开 53ms；前约 1.1–1.3 秒到达品牌区，
随后约 2.75 秒用于编织，各阶段首尾连续缓动。外部引线在后半段由尾部收束。
四处交叉以局部下穿留隙及同一绳线重绘表达上下关系，最终仍是曲线，不替换图片。
完成后静止；不添加常驻呼吸计时器。关闭按当前进度反向，完整反向时长 1450ms。
真实代理拥有状态只读接入，与上一版触发条件相同；UI 不调用代理开关或改网络设置。
详情页期间暂停同一时钟，返回继续，不重放；离开活动页时按当前状态收尾，减少动态效果时直接落到终态。
若代理在详情页或最小化期间改变，直接更新到对应终态，避免返回后播放过时动作。

视觉参考为用户提供的 macOS 截图和 [FlClash 官方仓库展示](https://github.com/chen08209/FlClash)，
未运行 macOS 版，也未复制其代码、配色或布局。
实现依据：[Qt ShapePath 裁切与曲线控制点](https://doc.qt.io/qt-6/qml-qtquick-shapes-shapepath.html)、
[Item 坐标映射](https://doc.qt.io/qt-6/qml-qtquick-item.html#mapToItem-method)。

## 你自己操作：五根引线与中断

1. 在活动页点击原来的系统代理开关，等实际开启成功。不要靠点卡片触发动画。
2. 看五个不同锚点是否各出一根绳：青蓝、湖绿、柔紫、珊瑚红、暖橙与对应卡片匹配。
3. 看路径是否沿留白弯曲前进，有少量错峰；不能穿过正文、速度、图表或按钮。
4. 等约 4 秒，查看中心交叉是否有上穿/下穿、末端连续闭合；不能在结尾闪换图片。
5. 成结后再等 10 秒：外部引线消失，只保留稳定祥云结，不转圈、不反复播放。
6. 关闭代理，查看是否沿当前形状收束到消失。重新开启后，在约 0.5 秒、1.5 秒、3 秒分别试一次关闭。
7. 关闭尚未结束时，再开启。预期从眼前的位置转向，不闪白、不凭空多出绳子、不留残影。
8. 若开启失败，观察真实错误提示；不能因为动画造成按钮假成功、额外开关代理或错误消失。

## 你自己操作：DPI、跳转与点击

- [ ] Windows“设置 → 系统 → 屏幕 → 缩放”，依次试 100%、125%、150%、175%、200%。每次先最大化 Swirl，再做一次完整开关。
- [ ] 特别检查 150%、约 1520×992 的窗口：保持双列五卡；系统最小高度可能将实际高度限制在约 1008 物理像素。
- [ ] 边编结边拖动窗口边缘、展开/收起侧边栏：绳头仍贴着对应卡片，不留在旧坐标。
- [ ] 若有两台不同 DPI 的显示器，将窗口拖过去：文字/线条清晰，锚点不漂移。
- [ ] 逐渐缩窄到现有紧凑布局后滚动：引线沿外侧留白，随内容滚动；绳线不截获滚轮。
- [ ] 保持同样的物理宽度时，175%/200% 的逻辑内容宽度可能低于原有 736dp 断点，进入紧凑布局是原有规则。放宽窗口后应恢复五卡。
- [ ] 编织中依次点开五卡，按 ESC 返回；再试返回按钮及刚开始展开就按 ESC。共享表面仍从真实卡片出发、回到原位。
- [ ] 成结后多次进出详情，不重新播放完整编结；编织中进详情，返回继续同一进度。
- [ ] 编织时点筛选、诊断刷新、列表行、滚动页面：各控件照常响应。
- [ ] 编织中切走活动页、最小化再恢复：不出现重复引线或明显跳变。详情页/最小化期间若改变代理状态，返回应展示最新状态。
- [ ] 开启“减少动态效果”：直接显示对应终态，没有长动画。Tab 焦点可辨认，Enter/Space/ESC 正常。
- [ ] 最后检查深色模式和增强对比：内容仍可读。增强对比/键盘焦点的明确边界属于无障碍反馈，不是普通卡片描边。
