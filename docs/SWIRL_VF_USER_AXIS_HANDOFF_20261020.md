一个跨 32 面共同匹配这些字宽观测的解释是：按源 fvar 默认值归一化，

独立反推用四个 GID 的实际字宽同时拟合源 HVAR 两段仿射模型。
3048 次反推均可匹配四维观测，报告的最大拟合残差为 0。
这是针对这些 HVAR 度量观测的结果，**不是原版轮廓的用户坐标映射通过**，也不是连续空间证明。

记录完全一致，另外 141 次相差一档；不能把这种尚未确定的舍入细节直接写进生产映射。
源默认值附近还需重点检测行为突变，不能用平滑替换原始行为来制造通过。
