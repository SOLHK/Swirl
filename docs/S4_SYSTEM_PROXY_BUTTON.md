It also documents that preconfigured WinINet access reads `ProxyEnable`, `ProxyServer` and `ProxyOverride`. Those observations support testing the actual readback rather than assuming independent stores: [Setting and Retrieving Internet Options](https://learn.microsoft.com/en-us/windows/win32/wininet/setting-and-retrieving-internet-options), [Enabling Internet Functionality](https://learn.microsoft.com/en-us/windows/win32/wininet/enabling-internet-functionality).
