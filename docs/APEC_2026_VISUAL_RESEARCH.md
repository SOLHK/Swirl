## 3. 实际视觉观察

### 3.1 会标的曲率、方向和负空间（A/B）

这是两组有共同动势的曲线，不是一组等距平行线。两条较宽主流线在下方交织，形成视觉承托；短羽翼从较低的内侧区域向外上方展开。外端较饱满，内侧逐渐收尖，长度与曲率随展开位置变化。短翼之间的白色通道让每片形状独立可辨，又让视线沿共同弧向移动。

整体近似宽浅弧，重心压在下部而两端上扬。中央文字占据开阔负空间；曲线没有穿过字形。复杂度被集中在边缘和底部，阅读中心相对安静。标志的轻盈首先来自留白、收尖和共同方向，不依赖大量高光。

**Swirl 转译**：保留 Swirl 原有轮廓和旋转识别，使用相切连续的长曲率转角，少量内部流带采用不同长度与宽度。保留中心负空间，避免把内圈填成彩色团块；不采用鹏鸟外轮廓、不复刻 21 羽翼及其分布。

### 3.2 色彩不是五色等分渐变（A/B）

左侧主要是橙色到红/玫红的暖色家族，右侧是浅蓝到青、绿色的冷色家族；较强的红色集中在底部主曲线，绿色靠外端。深蓝在会标文字上承担稳定的阅读锚点。图形里的蓝偏明亮，不能据此把文字深蓝与青色混成同一语义角色。

颜色在曲线所属的形体上变化，冷暖两路之间由白色负空间和局部交织隔开。这里的“橙、红、蓝、青、绿”是整体观看顺序和色彩家族关系，不能直接翻译成所有组件共用的五段等距 LinearGradient。

**Swirl 转译**：品牌采用暖色短段和冷色长段，交互强调维持青蓝单一主色；渐变属于品牌图形、连接状态和少数关键反馈。正文、数据表、普通按钮保持稳定颜色。错误红与品牌暖色要用文字、图标和位置进一步区分。

### 3.3 官方宣传海报存在不同艺术体系（D—H）

水彩系列采用纸感浅底、金色衬线式标题、植物和山海；玻璃系列采用浅青白底、深蓝粗体标题、半透明彩色流带及细线城市背景。不能宣称“全部官方物料只使用一套海军蓝玻璃视觉”。Swirl 此次应有意识选择后者的清晰层级和材质方法，避开水彩纸底对软件中性白背景的干扰。

玻璃羽翼海报把高饱和材料集中在底部与右侧，主要文字仍然具有完整浅色阅读区。轮廓以薄的深色反射边、局部亮边与透射色组成，内部并非均匀白蒙层。宽带之间的遮挡、透叠和色深差建立空间；高光沿曲面局部延伸，并不在每个形状周围均匀描白线。

横版山海海报保留宽广天空区域，把材料波峰放在下半部；一条亮弧把前景与远景关联起来。远处色彩更淡，前景局部更饱和，层级来自密度和清晰度变化。

**Swirl 转译**：玻璃导航是浮在内容背景上的独立容器；通过真实背景采样、低幅折射/模糊、方向性边缘光、柔和落影与清晰前景内容建立层次。不要用所有卡片透明化或整圈白描边代替材料。内容区应大部分平静，避免流带穿过表格文字。

### 3.4 背景适配与排版（A/B/D/E/I）

白底会标使用深蓝字；宣传片蓝天封面中的会标使用白色字，并保持彩色图形。这只能证明实际物料存在这种对比度适配，不能据此推导未公开的完整反白使用规范。海报标题与正文使用大幅字号差、紧密主题组块和宽阔外边距；Logo 位于留白位置，与标题、插画有独立空间关系。

**Swirl 转译**：产品字标使用深海军蓝，暗色背景提供对比清楚的反白字标。小图标应有专门的简化与光学校正；导航、标题和数据应形成三个稳定层级。对齐和留白优先于增加卡片边框。

### 3.5 动态素材核验与限制（I/J）

实际打开官方播放器并开始播放，查看了蓝天封面和片中的印度尼西亚山海场景。可见封面标题将羽毛与文字联结，随后进入地域叙事；官方说明确认羽毛贯穿亚太地域并最终汇聚鹏城。本次没有完成逐帧跟踪、羽毛轨迹重建或缓动曲线测量，不能声称测得官方运动速度、阻尼、错峰间隔或配色循环周期。页面操作多次超时，因此视频关键段的时序分析仍是研究限制。

**Swirl 转译**：借鉴“一个连续路径串联多个状态”的叙事方法。软件 Motion 必须自行设计并以操作目的验证：连接开始聚拢，成功后短促展开，稳定连接进入静态或低幅反馈，断开沿同一空间关系收束。宣传片的长镜头、飞行与镜头切换不能直接搬成持续桌面动画。

## 4. 建议给 Swirl 3.0 的独立视觉语言

以下全部是 Swirl 自行设计的起点，不是官方色值或官方规范。
此处是研究阶段建议；落实到品牌母版和后续工程的选定值，以 `SWIRL_V3_APEC_DESIGN.md` 为准。

| 范畴 | 建议 | 设计依据与验证要求 |
| --- | --- | --- |
| 背景 | 中性近白 `#FBFCFD`；表面纯白与极浅冷灰分层 | 遵守用户明亮中性要求，不照搬海报纸感或青底 |
| 文字 | 深海军蓝 `#142B4A` 起步；次级文本使用去饱和蓝灰 | 从“深色阅读锚点”转译；正文需实测对比度 |
| 交互 | 青蓝 `#007F9E` 起步；Hover/Pressed/Focus 独立 tokens | 高饱和色集中在动作与状态，避免五色按钮 |
| 品牌 | 橙 `#F49345`、珊瑚红 `#F34F68`、蓝 `#356AE6`、青 `#19BCD0`、绿 `#65C789` 起步 | 暖色短段、冷色主段；路径参数决定色彩位置，不等分填满控件 |
| 曲线 | 保留现有 Swirl 大轮廓；长曲率转角、渐收内端、少量分层流带 | 学习展开方法，保持品牌独立性；检查 16/20/24/32px 可辨性 |
| 玻璃 | 可读实色前景＋实际背景采样＋局部折射＋柔和影＋单侧高光 | 来自海报材质观察；最终需在 Qt/Windows 上真实渲染验证 |
| 组件 | 导航容器圆角大于输入框；行、分组、工具栏承担信息结构 | 避免全胶囊和卡片堆叠；小控件保持密度 |
| 页面 | 留白让出阅读中心；品牌动态集中于连接/状态区 | 从海报文字区与材料区的密度分配转译 |
| 动画 | 原位置有来源，目标状态有终点；沿弧展开，少量错峰，短暂光流 | 方向连续性先于装饰；状态变化必须绑定真实业务结果 |
| 渐变运动 | 颜色随曲线路径参数推进，局部高光随状态变化；稳定时收敛 | 不平移整个彩虹矩形，不持续模拟不存在的网络活动 |

## 5. Motion 落地的具体检查约束

1. 导航选中态可采用弧向位置插值与轻微宽度舒展，但文本和命中区域保持稳定，切换过程中不丢失键盘焦点。
2. 页面共享元素维持连续位置；进入/退出与侧栏指示器协调，不能切页白屏或让所有组件同时从零重新生成。
3. 连接与订阅动效直接消费真实状态枚举；视觉“成功”只能由真实完成事件触发。未知进度使用不确定状态，不伪造百分比。
4. 渐变/高光时钟仅在可见且需要反馈时运行；窗口不可见时停下装饰更新，保留业务状态。
5. Reduce Motion 使用更少位移和更短材料变化，仍保留状态变化和焦点反馈；不能把可访问性降级为功能缺失。
6. Token 应区分微交互、导航、浮层、状态展开、实时图表等用途，具体时长、弹簧参数与 GPU 成本交给 Qt 原型测量后确定。
7. 本研究没有证明任何 Qt 渲染性能、Windows 原生背景模糊、120Hz 帧时间或最终视觉验收；这些都属于后续工程验证。

## 6. 研究结论的边界

已完成：官方会标事实核验；多张官方会标与深圳传媒海报的实际图像观察；冷暖分工、曲率、负空间、两类海报体系、玻璃层次与背景适配分析；官方视频来源、发布日期和播放器实际播放核验；原创 Swirl 转译原则。

未完成/未确认：完整公开 VI 手册；官方色彩数值；官方字体/曲线/净空精确规范；宣传片逐帧时序分析；最终 Swirl Logo 小尺寸实测；实际 Qt 材质/动画性能测试。不要将这些项目写成已通过。
