接续 `work/swirl-ui-v2-20261024` 的阶段 3 节点资源库、阶段 4 策略与阶段 5 来源管理。版本设为 **0.2.6 诊断版**。本文件说明源码和验证边界；最终提交、CI、精确安装包身份以交付记录为准，不能据此认定安装包或真实供应商联网已通过。

## 设计与实现

Hallmark 按 app screen 范围应用：保留原生窗口、字体系统和导航结构，用密度与对齐组织实际数据，避免营销页结构和装饰卡片。UI UX Pro Max 的渐进披露、键盘焦点和可取消状态过渡，以及 Motion Design 的短反馈、减速入场、加速退出，均映射到已有 QML 组件。Qt UI Design/QML 负责本地实现；没有网页 UI、Lottie 或新动画框架。

- 主背景 `#F3F4F5`、内容 `#F8F8F9`、侧栏 `#ECEEF0`、浮层 `#FCFCFD`；文字与输入等统一从 Theme 取语义颜色。侧栏仍是原导航结构、尺寸、浮动边距及选择胶囊，背景由共享连续轮廓 Shape 填充。
- 窗口和侧栏使用同一个 **14 逻辑像素** 圆角目标，保留原 2.5 次幂曲线、抗锯齿和匹配阴影。最大化/全屏仍为直角。内容缩放不会再改变外框半径；Windows DPR 继续由 Qt 映射。
- 修正 Main 对 SwirlGlassMaterial 的不透明 `color` 覆盖。兼容系统轮廓时可使用文档化 `DWMWA_SYSTEMBACKDROP_TYPE=DWMSBT_MAINWINDOW`。本产品使用精确 14dp 轮廓；实验中的非激活 Mica 辅助窗虽返回成功，活动/非活动合成像素差为 0，未据此宣称壁纸材质完成。精确轮廓改为复用原有原生 compositor blur 路径，保留不接收输入、不激活的材质表面；没有引入新的模糊实现。外围不透明带与原生 inset 按同一 DPR 公式计算，不允许在未覆盖边缘露出未模糊的桌面。浅色 QML 仅叠加 94% 中性遮色，文字与控件 opacity 保持 1。
- 材质创建、区域、DWM 或定位失败时销毁原生表面，QML 底色恢复 alpha=1；关闭透明、远程会话、软件渲染、高对比或省电策略均保留安全回退。没有降低窗口整体 opacity，没有桌面截图、CPU 模糊或整窗文字纹理。
- Activity 的四列事实原位保留，直接点击“规则分流”文字打开原生菜单；按用户修正移除文字旁的常驻状态标签与下拉图标，不能呈现为旁边新增一个按钮。停机的“下次连接生效”放在菜单/提示中。显示值来自确认后的控制器状态；在途保持旧显示，不用动画完成回调确认配置。旧配置迁移和恢复仍在策略页完成。
- 菜单按 170ms 入场、110ms 退出，保留当前位置接续；列表新行用独立 Translate 的 6dp 残差，不从绝对 y=6 飞入。池化停止旧时钟、关闭旧菜单并清理位移/透明度。现有页面、详情、滚动和交互效果保留，减少动态效果使用原策略。
- Profiler 定位到启动提前实例化重写规则编辑器；改成首次打开时异步加载，随后复用同一个实例，保留局部选择、焦点和动画，不删除重写功能。连续请求仅消费最后一次打开意图，Esc 和页面导航可以取消尚未打开的请求。

原生 Mica 的 API 成功不能单独证明壁纸材质已经可见。本次精确轮廓交付使用原生模糊，Mica 辅助窗的未确认实验记录予以保留。最终 native fixture 会改变自有背景窗口的颜色并检查轻微的合成色彩响应；它不更改用户壁纸或系统显示设置，也不能替代主观材质验收。

## 检查点与证据

忽略目录 `work/stage6-build/` 保留构建、UI 输入、轮廓和审查记录；`D:/Codex/measurements/swirl-ui-v2-stage6-20261025/` 保存 profiler 原始 trace。源码边界工具没有重录历史 hash，只放行明确授权文件，并独立检查窗口默认/最小尺寸、侧栏结构/边距/选择尺寸及共享半径消费路径。

检查点中原生节点页 590 条业务断言通过，但一次标准查找快捷键的 QML 警告导致进程退出 2；另一次策略业务检查通过，但模式初始化绑定循环导致退出 2。两者均按失败保留，分别改用 `sequences` 和避免懒绑定求值同步写回后重跑。最终进程退出、QML 警告和计数由最终记录说明，不用断言通过掩盖警告。

代表性 DPR=1.5 的实际合成轮廓检查确认 14dp=21 物理像素，四角外无浅色材质方块，阴影随移动不重建。复用原生模糊后，自有背景换色产生 18 的 RGB 总差，确认存在实际轻微桌面色彩响应。第一次较宽窗口回归的比例采样取到了材质内部而非外围，导致 3 条旧假设失败；保留图像核对显示真实外围像素 alpha=255，换色前后均为 `(242,243,244)`。改为距边缘 2 物理像素采样，侧栏与工作区分别按新层级检查，再独立重跑。完整 DPR 人工观感仍由用户验收。新模式、延迟加载和来源管理的原生检查已加入既有测试入口，最终状态仍须读取对应运行报告。

基线 profiler 已发现长帧：原生帧采样 P99=62.7062ms、超过 50ms 的帧为 9。它是本机 240Hz、DPR=1.5、D3D、Qt 6.10.3 下的附加 profiler 场景，不能描述为稳定 60FPS。最终 trace 单独报告，不把不同场景、不同源码或不同计时口径直接合并为改善百分比。

提交前最后检查点：节点 UI 590/0、策略及文字切换 UI 250/0、实际窗口材质回归 70/0；进程均退出 0。包含标准查找快捷键、模式完整四字不截断、菜单边界、Esc 回焦点、真实事务待确认值及离线回执。代表性原生圆角/材质检查 0 失败，7 项 portable boundary 和新版 UI 尺寸/导航边界检查通过。早期警告/失败仍在原目录保留。同提交最终构建、profiler 和 CI 不能用这些提交前检查点替代。
