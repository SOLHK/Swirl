三段用户录屏都是 30 fps 的拍屏。第一段约 15 秒可见节点内容重叠，第二段约 21 秒可见多块导航底色，第三段展示活动页的滚动与首屏布局问题。拍屏不用于推导 GPU 帧率。

## 统一规则

逻辑像素经现有 Theme.dp 用户缩放，Qt 单独处理 Windows DPI：页面边距 24，区域间距 20，卡片间距 16，内部留白 20，紧凑间距 8；主卡片/弹窗 20，嵌套分组 12，矩形控件 10，胶囊 height/2。使用普通圆角，不宣称超椭圆。继续使用 RectangularShadow，未添加离屏动态蒙版、模糊或新运行依赖。

SwirlMotion：hover 120ms，按下 80ms，松开 190ms，分段 210ms，侧边栏 260ms，普通页面 190ms，关联表面 360ms，弹窗/详情 264ms。减少动态效果直接提交几何，保留状态、焦点和原生滚动。标题/图标不随背景缩放。

## 内容区与路由覆盖

- 活动：连接概况、四个等高指标、7:5 趋势/网络质量、独立流量来源。上传/下载/累计流量使用对应 key 和真实目标表面，返回恢复原滚动。网络诊断在同一真实卡片边界展开。
- 概览：响应式网络接管、局域网、远程连接服务分组，保留原操作与错误检查。
- 进程/设备/连接/节点：稳定列表、固定方向详情；更换已选条目更新现有面板。节点保留真实连接、测速状态和编辑逻辑。
- 捕获/日志：增量记录、稳定选择、历史阅读位置；未改变捕获数据保存和后台网络采集。
- 规则/重写/策略/解密/设置及其余已注册路由：通过共享按钮、圆角、分段、对话框、页面宿主和表格组件应用统一规则；保留原编辑、搜索、确认、证书与服务语义。全部注册页面 smoke 覆盖。没有把未实现功能改成假数据。
- 更多：保留原生设置窗口与已有返回来源；不伪造跨进程共享元素。现有 native sheet/节点/订阅展开的 Hero 测试通过。

窄窗口复测曾发现设置页固定双栏使主题选择器越界，原生测试因点击窗口外而超时。已改为自适应表单、加入命中区边界断言，并在 800 宽窗口复测通过（appearance-recheck.txt / final-ui-recheck.txt）。默认启动宽度保持 914。

窗口最小宽度放宽到 760，侧边栏仍为 208、原分组/入口/窗口按钮位置不变。800×672 实际窄窗口采用两列指标，分析区上下排列。原 800×600 截图请求曾被旧最小尺寸约束钳制，不作为窄窗口证据。

## 性能条件与数据

Qt 6.10.3 / MinGW 13.1 / Windows x64 Release / D3D11 / NVIDIA GeForce RTX 5060 Laptop GPU / threaded render loop。
窗口 914×672 逻辑像素，DPR 1.5，屏幕报告 240Hz。每 16ms 发送滚轮输入并请求帧，30 秒中每 40 次输入反向；这是一项约 60Hz 输入/持续重绘负载，不是 240Hz 满帧测试。
本机 SOCKS5 fixture → 实际生产网络引擎 → HTTP origin。前后各完成 287 个经代理转发的真实请求，统计 sampled=true，约 68KB 计入累计。没有启用系统代理/TUN或导入用户节点。

下表依次为 p50 / p95 / p99 / 最大值，单位 ms；来自未启用 QML Profiler 的独立运行。

| 指标 | 修改前 | 修改后 |
| --- | --- | --- |
| Qt 帧交付间隔 | 16.589 / 16.999 / 19.391 / 39.749 | 16.588 / 17.013 / 20.764 / 29.254 |
| GUI 输入分发 | 0.145 / 0.230 / 0.331 / 0.500 | 0.137 / 0.237 / 0.316 / 0.545 |
| 场景图同步 CPU | 0.001 / 0.082 / 0.102 / 0.335 | 0.001 / 0.046 / 0.091 / 0.149 |
| 渲染提交 CPU | 0.131 / 0.312 / 0.598 / 1.113 | 0.135 / 0.322 / 0.551 / 1.063 |

大于 33.33ms 的帧交付间隔：1 → 0。实际 contentY 范围前后均为 0–72，包含反向滚动。
**结论有限：p95 基本持平、p99 没有改善；最大长帧下降不等于已证明所有场景不卡顿。** Qt frameSwapped 不是硬件呈现 FPS，渲染提交 CPU 不是 GPU 时间。不能据此宣称稳定 120/240 FPS。60Hz 的 16.67ms 和 120Hz 的 8.33ms 仅作为参考预算。

单独的 QML Profiler 跟踪（不混入上述帧时间）记录绑定、JavaScript、信号、painting 和 scenegraph。分析最后 30 秒、排除创建期：

- 日图数据准备：原 records 绑定 121 次、累计约 60.78ms；新 refresh 41 次、累计约 31.73ms。绘图刷新合并，未改后台采集。
- 原排行绑定 121 次；新合并快照 refreshSnapshot 62 次。后者同时包含汇总、分布、排行和局部 UI 交还，不能把两个累计时间当作同一函数的严格加速比。
- 仍可见 currentNetwork 的低频查询热点，约每 10 秒一次、最慢约 4.26ms；没有证据需要为它更换渲染框架。
- inclusive 时间会嵌套重叠，不能相加当作 GUI 线程总占用。完整 trace、CSV 和 JSON 随交付提供，可在 Qt Creator 复查布局相关绑定与绘制事件。

## 验证与边界

- 115 项交互断言在 D3D11 的 100%、125%、150%、200% Qt 进程 DPR 下通过；包含快速导航 30 次、普通按钮拖出/键盘、关联转场立即返回/再打开、源表面恢复、滚动缓存、代理局部面板位置、ESC/反向关闭/焦点恢复、减少动态效果及闲置资源。
- 13 组业务回归通过：字体选择/原生栅格、本地扩展、节点链路、native engine、订阅格式、订阅导入、引擎契约/实际进程、节点 UI、引擎 UI、网关隔离网络、捕获网络。
- 流量记账（含新增缓存失效与断连保留历史）、诊断导出、页面 smoke、概览原生输入、外观、Hero 既有测试通过。最终结果以交付原始 JSON/日志为准。
- 100/125/150/200% 是同一物理显示器上的 Qt DPR 模拟，未修改系统显示设置；不是跨物理显示器验收。
- 尚未验证：用户公网节点下的长期大流量/大历史排行、真实触控板硬件输入、跨屏 DPI 迁移、稳定 120Hz、权限/证书安装失败的系统级矩阵。系统代理恢复测试会修改系统配置，本轮未运行；安全前置检查保留。
- 录像是实际 QQuickWindow 帧采集，用来检查几何和交还；截图读回会影响录制时序，不能作为帧率测试。

## 复现

按 BUILDING.md 配置 Release 和 SWIRL_BUILD_UI_TESTS=ON。运行 scripts/Test-Interaction.ps1 可产生隔离滚动报告，-Live 使用真实本机代理链，-Profile 另存 QML Profiler trace。生产包使用独立 SWIRL_BUILD_UI_TESTS=OFF 构建，不包含这些测试/Profiler 运行入口。实际部署包在移除 Qt 开发工具链 PATH 后，以既有隔离截图入口启动活动页和设置页，均以 0 退出。

参考：Qt Quick Performance、Flickable、RectangularShadow 官方文档。仅使用本机 Qt 6.10.3 已验证 API，没有引入 Motion React、Rive、WebView 或新字体。
