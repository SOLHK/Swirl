## 自研边界与模块

最终产品中协议、握手、会话调度、DNS、路由、UDP、传输、流量统计、质量监控和配置执行由 Swirl Rust 控制。
禁止运行、重命名、嵌入或隐藏 Mihomo/Clash/sing-box/Xray/V2Ray 等完整代理内核；禁止失败时偷偷回退，
或借其他本地代理转发后冒称原生验收。参考核心/客户端/服务端只作隔离互操作对照。
允许成熟 TLS、密码学、QUIC、HTTP/2/3、异步 I/O、JSON/YAML/TOML、压缩和必要 TUN 驱动。
明确依赖版本、来源、许可证和作用，不自行发明加密/随机数/证书验证。

Cargo Workspace 职责：swirl-core（运行时/生命周期/资源），swirl-protocol（代理协议状态机），
swirl-transport（TCP/UDP/TLS/WS/HTTP2/gRPC/QUIC），swirl-routing（域名/IP/CIDR/GEOIP/GEOSITE/组），
swirl-dns（系统/UDP/TCP/DoH/DoT/缓存/分流/泄漏防护/Fake-IP），swirl-tun（平台虚拟接口），
swirl-subscription（下载/适配/参数/版本/兼容），swirl-api（稳定控制接口）。
模块可合并拆分，但不添加空壳来充数。不删除仍有效的旧功能来宣称迁移完成；每个替代先实现并验证。
Rust 专用构建显式禁止完整外部内核；最终检查依赖、包内容、进程树和流量路径。

## Swirl IR 与兼容矩阵

内部使用独立 Swirl IR，不把 Mihomo YAML 当唯一内核配置。结构化保存来源/格式版本、协议版本、服务器端口、
认证、TLS/SNI/ALPN/校验/指纹、传输、UDP、多路复用、链式代理、DNS、规则、组、远程资源、未知字段和转换诊断。
同名不同语义字段不可混用。安全/握手关键项不支持必须失败，不能丢掉再连接。
完整配置的脚本/重写/MITM/私有组网单独列账，不自动执行订阅脚本或命令。

四层状态严格分开：识别格式、准确解析/转换、原生可执行、互操作/真实联网验证。
矩阵维度：客户端/格式 × 版本 × 协议 × 传输 × 关键参数 × TCP/UDP，并记录证据环境。

客户端调查至少覆盖 Clash/Mihomo/Verge Rev/FlClash/Meta、sing-box/Hiddify、v2rayN/v2rayNG/V2Ray/Xray、
NekoBox/NekoRay、Surge、Shadowrocket、Quantumult X、Loon、Stash、Surfboard、Egern、Karing、Streisand、V2Box
及实际出现的其他导出。区分共享格式和特有扩展，不按软件名重复实现。
输入包括 URI、多行 URI、Base64/URL-safe、YAML/JSON/INI、完整配置/节点订阅、编码/BOM/换行、压缩、
合法 UA、代理集合、远程资源、元数据和版本差异。全部本地转换，不送第三方转换站。

目标协议：HTTP/HTTPS CONNECT、SOCKS4/4a/5、SOCKS5 UDP、Shadowsocks AEAD/2022、SSR、VMess、VLESS、
Trojan、Hysteria/Hysteria2、TUIC、AnyTLS、NaiveProxy、Snell、Mieru、WireGuard、SSH 及实际样本中的其他协议。
单独核对 TLS/REALITY/XTLS Vision/flow、TCP/WS/HTTP2/gRPC/HTTPUpgrade/XHTTP/HTTP3/QUIC、ShadowTLS、
混淆插件、多路复用与 UDP 扩展。只实现有规范和样本支持的合法组合，不任意拼接。
每种协议覆盖参数校验、握手、认证、成熟密码库、封装、TCP/UDP、超时、取消、关闭与互操作。
资料不足继续查官方信息，不虚构私有握手，不用第三方内核绕过缺口。

## 一次性订阅采集与十分钟授权

顺序不可倒置：

1. **先准备并验证工具**：批量下载、可用网络、格式无关原始响应、加密持久化、有界并发/重试/大小、截止、
   常见引用发现、完整性、失败清单、日志脱敏、离线导入重放。先用公开数据和本地模拟服务，不拿用户窗口调试。
2. **一条消息集中收齐**：所有已有平台/客户端导出、已知协议传输/版本、同源导出关系、共用开关分组、必要
   合法请求头、关联资源、已有授权范围。使用私密本地清单，密钥不进命令历史。没有的样本优先自建服务/公开规范。
3. **就绪再统一开启**：收到明确开启确认后立即批量获取根订阅与依赖，按网站实际开启时刻计时，分组截止并留余量。
   窗口内先下载、错误页判断、加密、摘要/元数据、依赖、结果；不穿插长测速。
4. **截止使用缓存**：不重开网站、不猜隐藏 API、不轮询、不继续后台重试、不删旧节点；不让缓存随窗口失效。
   失败集中报告，必要下一次更新再集中授权。节点凭据真实到期单独处理。
5. **引用与更新事务**：循环/深度/大小/目标/重定向有界，内容不能授权任意本地文件或网络，跨站不泄露认证。
   原始缓存与当前生效配置分离；校验后原子提交，失败保留最后有效版本；后台更新不重启内核或清空连接。

原始链接/密码/令牌/Cookie/私钥/账户/解密响应不得进入源码提交、公开 CI、日志、发布包、
Gemini 或转换服务。用户已授权使用私有 `Swirl-Private-Tests` 仓库中现有加密归档：
沿用其 Secret，仅在该私有工作流内存中解密和测试，只保留白名单脱敏报告，不重新下载订阅。
其他私有原始材料仍只保存在获准位置。交接只用合成/脱敏样本；此授权不包含修改系统代理/TUN。

## 可靠性、安全与测试

复用系统代理快照/所有权/恢复机制；他人接管不抢回，恢复不覆盖新配置。
不关闭防火墙、不改 WindowsApps 权限、不默认 TUN、不装无关证书、不静默改系统 DNS、不增加无必要常驻进程。
正确处理 IPv4/IPv6/域名、认证、错误返回、部分读写、取消、有界并发、UDP 边界/会话/MTU/回收。
TCP 成功不算 UDP 支持；TUN 与系统代理分开，Codex 不应被要求必须开 TUN。

CONNECT/WS/WSS/SSE：有界握手、背压、缓冲上限、半关闭、TLS 尾部/关闭、网络变化/休眠恢复。
不以固定短闲置超时杀合法长连接；不无限缓冲/重试、不关证书验证、不注入应用 WebSocket 心跳。
新连接用新决策，旧连接保留原出口；不宣称任意既有 TCP 可无损迁移，不重放有副作用请求，不静默直连。

每个 Rust 模块实际执行 fmt --check、check --workspace、clippy --all-targets -- -D warnings、test --workspace。
记录环境和不能运行的原因，提供等效验证。协议测试采用固定参考服务端，区分本地、互操作、公网、私有节点。
测试覆盖订阅错误/压缩/截断/401/403/429/到期/重复/原子恢复，协议认证/TLS/SNI/ALPN/分片/模糊输入/耗尽，
TCP/UDP/IPv6/DNS、切换/断网恢复、WS/SSE/大传输、系统代理恢复/TUN、异常退出与资源、真实统计/UI 不变。

性能可复现：吞吐、连接与 DNS P50/P95/P99、CPU/内存、并发、空闲、长时间/弱网。比较用相同条件。
不编造零延迟、永不断线、满速或提升比例。真实测试优先隔离端口；下载网络不等于原生验收路径。

诊断记录脱敏的构建、内核身份、配置代次、匿名节点、协议/传输、失败阶段、代理归属/端口、错误与环境。
区分订阅窗口、格式、参数、原生缺陷、节点、DNS/路由、TLS/认证、客户端绕过代理、服务端、用户主动断开。
不能仅凭状态码/WS1006/FIN/RST/能打开网页/端口监听就认定根因。
