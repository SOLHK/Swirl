## 数据与诊断

活动、总览、仪表盘、进程、流量分析及连接页共享认证 Mihomo 观测。系统代理模式只统计经过 Swirl 的流量。存储保留最多 63 天、3600 个采样点、2000 条近期连接及有界分类排行。相同连接按累计字节差值入账。采样失败显示未采集。

诊断记录真实引擎、订阅、测试、网络、Qt、GPU/HDR 与合成事件，最多 500 条可见事件，约 4 MiB 轮转日志。ZIP 包含脱敏日志、环境、允许名单状态及有限崩溃错误码，不含原始连接历史、节点配置、订阅地址、密码、Cookie 或认证信息。可显式检测 Codex 公开认证发现端点，分别记录 HTTP 与 Qt 错误；不读取 Codex 凭据，端点可达不等于实际登录成功。

## Surge 文档与模块覆盖

核对 [Surge 官方手册](https://manual.nssurge.com/) 的 88 个页面并补充用户验收细项。`SURGE_FEATURE_MATRIX.md/.json/.csv` 记录出处、中文归属、模块 ID、导航入口、实现程度、Windows 能力、未来工作及重复关系。

模块由 56 增至 69，新加 13 个入口。924 条对照记录包含文档章节、配置键、协议参数及验收细项，不等于 924 个已实现功能。关联能力共用唯一模块与统一状态；待开发功能不会宣称生效，平台专有能力注明限制。高级 TUN、MITM、DHCP、脚本引擎及专有格式兼容未在本阶段实现。

常用功能维持分组侧栏，其余从「更多 → 全部功能」进入，可中文搜索、分类筛选及查看状态。模块说明列出细项出处及状态。

## 本机真实证据

- Windows 11、C++23、Qt 6.10.3、MinGW x64 编译；MSVC Windows CI 以整合 PR 实际运行结果为准。
- 真实 DPAPI 节点副本共 180 个独立测试，159 成功、21 失败，成功请求为 HTTP 204；每节点结果只留本机。
- Google 首页、Google 搜索、YouTube 首页 HTTPS 请求 HTTP 200。40.22 秒限速下载收到 10,158,080 字节，155 个真实速度采样非零。**这是请求和下载测试，不是浏览器或视频播放验收。**
- Mihomo 实际连接确认 Google 代理、百度 cn-domain 直连；真实全局/直连/规则切换及独立系统代理开关验证，节点选择保持不变。
- 真实订阅服务器返回 HTTP 400、Qt 网络错误 302（不是 HTTP 302 跳转），旧节点保留。原始生产 DPAPI 文件 SHA-256 前后相同。
- 原生 150% DWM/Acrylic 检查 56/56，通过四角像素、实背景模糊、透明开关、浅深背景、主题、移动缩放、最大化恢复、按钮与系统菜单检查，有原生截图及四角 8 倍图。
- 实际 Windows 100%、125%、150%、200% 设置下保存运行窗口截图；100% 完整原生自动化因前景遮挡检查中止，不计为渲染通过。截图与完整自动化覆盖分开记录。
- 开启实际 Windows HDR 后，FP16 显示测试通过，三色按钮亮度高于 80 nit 白点；随后恢复测试前的 150% 缩放、HDR 关闭。
- 最终 CTest 13/13，原生系统代理 QtTest 9/9，最终原生窗口回归再次 56/56。实际软件回退在 150% 下记录为不透明、无 HDR、无原生圆角，原生窗口截图已保存。

最终 CTest、原生代理恢复、安装升级卸载及 CI 逐项结果随交付报告提供。早期失败与重试不会删除或混入最终通过数字。

交付验证发现同一生产 EXE 在原 QML 缓存下导航超时，切换全新缓存目录或禁用缓存后均遍历 74 个路由成功。参考 [Qt 6.10 缓存说明](https://doc.qt.io/qt-6.10/qmldiskcache.html)，现在按 QML 内容摘要、Qt 版本和测试/交付构建隔离缓存；保留旧缓存，不删除用户数据。CI 新增关闭 QtTest 后的冷/热两次生产导航，避免只验证测试构建。
