# PR #12：文字清晰度与节点交互验收

只更新 PR #12 当前开发分支，保留草稿和原有目标 `test`；未合并 `main`，未发布正式版本。

## 字体根因与修复

这次定位到三个不同问题，不能靠换字体或整体加粗解决：

1. `SwirlGlassPanel` 对整个卡片启用 layer 和 MultiEffect 阴影，子项文字也进入离屏纹理；公共表格还通过纹理遮罩裁角。背景阴影和文字因此共用合成路径。现改为只绘制背景几何的 `RectangularShadow`，表格使用视口裁切，前景不再进入卡片或表格 FBO。
2. 原代码虽然已全局设置 NativeTextRendering / FullHinting，但普通 QML `Text` 不会完整跟随运行中的应用字体更新。专项测试实际发现，切换字体后捕获页的标题、说明、复选框仍保留 HarmonyOS。新增 `SwirlText`，统一绑定 `Theme.fontFamily`、原生渲染、FullHinting，迁移 57 个页面与组件；输入框也显式设置原生路径。实时切换字体测试已从失败变为通过。
3. 11px 辅助文字、较浅文字颜色，以及按钮/下拉/对话框对文字整体缩放，加重了视觉发虚。字号下限改为 12px，默认正文 13px，常用标题 16/19/26px；保留普通正文原字重。加深辅助文字与蓝色文字/主按钮对比度，按压只影响背景，取消弹出控件中文字缩放，页面转场按当前窗口 DPR 对齐。

主要专项覆盖：活动页状态和卡片、概览、侧边栏、进程、策略节点卡、规则表格、HTTP 捕获、HTTPS 解密、节点详情、设置/订阅及公共按钮和下拉框。其余页面通过公共文本组件统一受益，并完成 61 页遍历。

系统 Desktop Acrylic 仍负责背景材质。常规窗口使用直接 SDR swapchain，取消整窗 HDR 后处理，避免文字为 HDR 色彩转换再次进入纹理。**既有 HDR 灯效本轮暂不默认启用**，独立 shader/FP16 诊断代码仍保留；HDR 桌面可正常显示该 SDR 窗口。恢复完整 HDR 前景色彩管理需要后续独立验证。

Qt 的离屏子树语义及原生文字在缩放下的限制可参见 [Item layers](https://doc.qt.io/qt-6.10/qml-qtquick-item.html)、[QQuickWindow 文本渲染](https://doc.qt.io/qt-6.10/qquickwindow.html)。字体不随实时切换更新的问题由本机运行时测试确认。

- 策略页将页码/翻页操作收进节点卡片，按钮层级统一，策略组空状态收紧；增加纵向滚动，防止最小窗口挤压内容。
- 规则搜索移入主卡片工具栏，统一表头和正文对齐，保留真实规则及研发中按钮，无假空行。
- HTTP 捕获统一说明文字行距、分组留白和公共控件，保留全部入口。
- HTTPS 解密改为证书/选项与主机名两个平衡区域；主机名显示计数、添加入口、真实列表和可操作的空状态，长说明可纵向阅读。

## 节点点击、筛选和数据流程

之前的停顿有两部分：选择节点会序列化整个节点库、DPAPI 加密并同步写盘，随后通知整张表重新装配和排序；详情卡还跨区域移动，并逐帧修改宽高、字号、透明度，完整操作区延迟揭示。

现在选择只原子保存不含秘密的节点 UUID 到 `.selected` 小文件。凭据、订阅 URL 和原始配置仍在 DPAPI 库中；选择不改写凭据文件，失败时保留原选择，失效 ID 不覆盖合法节点。独立 selectionChanged 通知避免选择时刷新节点目录。目录元数据和延迟/状态通知拆分，国家列表与名称排序只跟随元数据变化；表格仍复用已有行。筛选先批量剔除不匹配的旧键，避免对筛掉的大前缀逐行重复扫描。

详情和请求卡常驻右侧，点击处理时立即更新标题与操作区，移除跨列表飞行动画；颜色反馈保留。快速连点会显示最后选择的真实节点，不依赖动画结束。

新增“全部地区”筛选，可与搜索、协议和订阅来源组合。地区集合从当前来源的实际节点目录去重生成，没有对应节点就不生成选项；导入/更新/删除/切换来源会重新生成，已消失的选中地区自动清空。地区来自节点名的旗帜、国家/地区别名或独立 ISO 标记，旗帜优先；无法识别的条目归入“未标注地区”。不进行 DNS/IP 地理查询，不把名称标记冒充出口地理验证。

真实本地 HTTPS 订阅测试已覆盖 HK → JP 更新、仅当前订阅地区、来源切换、删除失效地区、搜索+协议+地区组合，以及更新失败保留已有节点。

| 125% | 1.25 | 178 / 0 | 178 / 0 |
| 150% | 1.5 | 178 / 0 | 178 / 0 |

共 8 组原生窗口检查，合计 1424 项、0 失败。每组检查可见文本使用所选字体、原生路径、至少 12px，且无离屏纹理或缩放祖先；也验证页面打开后实时切到微软雅黑的结果。苹方使用用户本机字体文件，仅加载到测试进程，未随源码或便携包分发。

- 节点 UI：123 项、0 失败；鼠标键盘页面输入：63 项、0 失败；61 页遍历、主题恢复、动画、诊断事件回归通过。
- 节点存储/地区/选择专项：6 个 QtTest 测试项通过，涵盖凭据文件不变、重启选择恢复、坏选择回退、保存失败和通知稳定性。
- 原有真实节点链路：17 项通过、1 项需明确授权的远程订阅测试跳过；订阅格式和导入回归通过。本轮没有用远程私有账号流量冒充验证。
- 最后一次 180 节点交互：11 次点击，派发耗时 8.49–11.54ms，平均 9.67ms；详情标题在处理点击时更新。相关交互断言 39 项、0 失败，另验证末尾节点筛选与清空恢复。
- 上述毫秒数是 QtTest 鼠标调用到处理返回的本机时间，包含测试派发开销，不是屏幕光子延迟。GIF 受截图读回影响，不用来证明 FPS。未实测切换 60/120Hz，不声称固定 240FPS。
- 生产构建关闭 `SWIRL_BUILD_UI_TESTS`，便携包使用同一最终源码并另跑页面遍历。GitHub CI 结果以本轮提交的远端记录为准。

早期一次输入测试因把 Windows 150% 的换算系数错误地用于 offscreen 虚拟屏，导致两个窗口尺寸断言失败；移除该环境系数后 63 项输入通过。实时字体切换的初次失败是真实产品缺陷，已通过 SwirlText 修复。失败记录没有当作通过证据。

## 已知边界

这些是单台电脑上真实进程 DPR 1/1.25/1.5/2 的覆盖，不等同四台物理显示器或系统 DPI 设置切换。200% 下预览尺寸受可用桌面限制，保留实际原图尺寸。其他 GPU、物理 4K/HDR、多屏跨屏与远程会话尚未完成同等验证。

正常窗口当前采用 SDR；原有 HDR 灯效不默认启用。国家按节点标记推断，未标注/含糊名称无法可靠确定物理出口国家，未新增地理数据库。未实现协议仍交由固定版本 Mihomo，已有研发中入口保持标记。卡片/文字清晰度的最终观感仍需在实际目标屏幕复核。

使用背景几何阴影后最低 Qt 要求为 6.9，CI 与本机构建仍使用 6.10.3。未经验证的 Qt 6.8 构建不继续宣称兼容。
