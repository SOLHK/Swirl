# PR #12 图形、动画与字体升级验收

本轮将 Swirl 的图形升级落实到现有 C++23 / Qt Quick / Mihomo 架构，保持 PR 草稿、目标分支 `test`。没有合并 main、发布正式版本或上传私人节点/订阅数据。硬件覆盖不足与明确允许的降级均列在下文，不能把开发完成等同于所有机器的实测验收完成。

## 最终界面行为

- 主窗口、设置窗口、独立面板采用同一层均匀淡蓝材质。按最终反馈降低透明感：浅色表面不透明度 0.96、深色 0.97，染色权重 0.72。不添加第二层侧栏或工作区底色、渐变、持续光晕。后方桌面仍有真实 alpha 贡献，正文卡片接近不透明。
- Windows `IDesktopWallpaper` 提供按屏幕映射的真实壁纸；解码异步、CPU 缓存上限 64 MiB，GPU 模糊纹理按 512/768/1024 档位缓存。移动只改变坐标，壁纸/屏幕/质量改变才失效重算。它不实时捕获后方应用，不应描述成对任意后方窗口进行动态模糊。DWM Acrylic/Mica 关闭，保留系统阴影和窗口行为。
- 窗口轮廓使用原创四阶超椭圆 SDF 与导数抗锯齿；普通卡片按最终反馈恢复原有圆弧曲率与 20 逻辑像素半径。透明关闭和软件渲染提供不透明回退。
- 活动页按信息量排版：网络诊断占半宽，上传/下载各四分之一宽，连接信息与总流量为紧凑卡片，趋势和排行合并为较大卡片。空数据明确显示未采集。
- 节点页改为简洁工具栏、胶囊主按钮、轻量图标操作、无斑马纹/网格线列表、局部选中背景、紧凑详情和请求设置卡片。右侧内容可滚动，避免长错误信息挤出操作。

## 转场与业务状态

`SwirlTransitionRegistry`、可逆协调器、页面缓存与原有 SwirlMotion 统一管理转场。复杂动画尊重减少动态效果、窗口可见性和系统节能状态；结束释放引用，空闲不维持动画时钟。

| 入口 | 实际行为与边界 |
| --- | --- |
| 更多 → 通用/外观/DNS/模块/配置/脚本/订阅/节点/字体 | 立即打开真实原生设置 Window；来源卡片收缩、目标淡入，Esc 返回并恢复来源焦点。采用附件明确允许的跨原生窗口降级；没有声称完整跨 HWND 卡片变形。 |
| 订阅卡片 → 详情 | 同一个稳定 ID 委托沿自身边界展开/收回，显示真实名称、节点数、状态、自动更新周期与操作；保留滚动位置。 |
| 节点行 → 详情 | 同一张真实局部详情卡片从被点行的位置和尺寸展开到右侧，返回原行；快速点击重定向，表格和壁纸不参与大范围缩放，不抓取整表纹理。 |
| 规则行 → 编辑 | 来源行关联编辑框，按真实规则索引修改，保持顺序并持久化；无效索引/数据回滚，不意外追加新规则。 |
| 策略组 → 编辑/成员选择 | 来源组卡片关联真实编辑表单，复用现有策略组 API；成员列表虚拟化。 |
| 活动网络诊断 | 原卡片展开真实诊断结果；刷新仍发起真实请求。 |
| 上传/下载/连接/总量/排行 → 既有详情 | 数值或标题局部共享；保留今日/本月条件，实际页面正常加载，避免全表转场。 |

互联网诊断改用实际 HTTPS 请求：引擎运行时经过 Swirl 当前代理端口，未运行时明确标记直连；分别报告 DNS、超时、节点/策略、端口拒绝、离线等状态。路由代次变化丢弃过期结果。测试验证真实受控 HTTP 204 与失败路径，没有伪造成功延迟。

## 字体与许可

默认内嵌官方原样 HarmonyOS Sans SC Regular/Medium/Bold，无需系统安装。更多 → 字体支持搜索系统字体、即时切换、导入 TTF/OTF/TTC、持久保存、恢复默认。用户安装或导入的苹方、MiSans 等可选，软件没有捆绑这些字体。

字体使用声明与完整官方协议在应用字体设置、关于页与分发包中提供。它采用 HarmonyOS Sans Fonts License Agreement，不能称作 MIT/OFL。固定提交、哈希和存储方式见 [FONTS.md](FONTS.md)。

为改善小字号清晰度，默认采用 Qt NativeTextRendering、原生字体 hinting、抗锯齿偏好和整数逻辑字号，最小字号 11。代码区域继续使用等宽字体。清晰度做原生 DPI 截图检查，没有编造客观锐度分数。

## 验证方法与结果

- Windows 11 x64 / Qt 6.10.3 / MinGW 13.1 Release，RTX 5060 Laptop GPU。主屏为 2560×1600、150% 系统缩放、SDR。
- 未改动基线 CTest 14/14；新增字体及共享转场后完整 CTest 16/16 通过（327.46 秒）。最后节点滚动布局再次跑节点与共享转场 2/2 通过；最终单层背景清理再跑字体/所有页面/共享转场 3/3 通过（66.15 秒），原生窗口矩阵也通过。没有将早期失败或旧包当作最新结果。
- 最终 100%/125%/150%/200% 进程 DPR 原生窗口检查均退出 0；每次 56 项，包括四角透明、真正后方颜色合成、最大化/还原/最小化、系统菜单、边缘缩放、浅深色与透明关闭。100/125/200 使用进程 QT_SCALE_FACTOR 乘以当前系统 150%，不是更改 Windows 系统缩放。最终节点/活动/字体窗口截图由真实 Qt 渲染生成。
- Gaussian、Kawase、原创 Dual Kawase RHI 与 MultiEffect：1080p/1440p/2160p 共 12 个受控离屏 GPU 用例通过；各 40 个 GPU 时间戳样本，模糊 PSF sigma 独立校准到约 6 像素。这是模糊重算成本，不是整应用显示 FPS。
- 官方 RenderDoc 1.46 实际获得 D3D11 RDC：初始帧 26 draw calls，随后两个缓存帧各 2；截图读回重绘帧 31。该记录支持缓存减少重绘，不足以单独证明所有页面均为 2 draw calls。工具不随生产包。
- 物理面板实际支持 60/120/240 Hz，刷新率变化后 Qt 同步识别。最终独立性能报告通过自身 D3D11 flip swapchain 的 DXGI 呈现计数与 QPC/vblank 同步统计，不以屏幕 Hz 或 Qt 回调频率充当 FPS。只统计同一声明动画时间窗内的呈现跨度，排除截图读回/空闲阶段，并保留漏刷。数值以交付的 PERFORMANCE.json 为准。
- 最终有效跨度统计：60Hz 约 60.00FPS，120Hz 约 119.59FPS，240Hz 约 236.60FPS；显示间隔 P95 分别 16.667/8.333/4.167ms，P99 分别 16.667/8.333/8.333ms。240Hz 仍有漏刷，且一个内部计数不一致跨度（呈现增量 3、vblank 增量 2、8.333ms）已从 FPS/分位数剔除并保留原始数据；另一次 API 未给出可用统计。该表描述有效样本，不补造缺测值，也不保证任何机器恒定满帧。
- 早期 PresentMon ETW 60Hz 数据有效；120/240Hz 阶段测试窗口曾被遮挡，不能使用那些零样本宣称高刷结果。后续提权采样被系统取消，改用不需提权的 DXGI 数据；未隐瞒失败记录。DXGI 的多屏/其他全屏应用限制见 Microsoft 文档。
- 540 次页面/订阅交互的较长压力回归通过，资源结束后私有内存比预热增加约 5.48 MiB，GDI 句柄未增长。另做最小化 60 秒 CPU 统计，具体原始值随报告提供。单次压力运行不能证明绝无长期泄漏。

## 图形依赖与可选方案

FXC 已补齐，Rive 原始着色器编译成功，但 MinGW DirectX COM/RPC ABI 编译失败；隔离 OpenGL-only 实验也未通过插件桥接链接，因此不纳入生产，使用原生 QML 状态反馈。可选 MSVC + 匹配 Qt 套件未验证。FluentUI Release 研究插件已编译成功，但不作为 Swirl 运行依赖。Effect Maker 原创短暂点击高光导出通过；Skia、Qt Shapes、Dual Kawase 示例只研究几何/算法，不复制第三方 UI 资产。具体提交、许可及错误证据见 [ANIMATION_DEPENDENCY_RESEARCH.md](ANIMATION_DEPENDENCY_RESEARCH.md)。

## 尚未覆盖的验收条件

物理 144/165Hz 模式不可用；实体 4K/HDR、多屏跨屏、其他 GPU、可选 MSVC/Rive 尚未实测。没有宣称点击到光子的硬件延迟测量或不同硬件上的恒定 240FPS。研究中遇到的上述限制不阻止现有生产路径运行，但这些项目仍属于待验证范围。

PR 原有未实现功能仍如实保留边界：完整断点/回放、部分高级 API/自动化/同步与进程合并显示等并未在本轮凭空完成。捕获并非全网卡 PCAP，HTTPS 需要显式捕获代理，HTTP/3/Upgrade 等限制见 CAPTURE.md；本地脚本/模块格式并不兼容 Surge API/.sgmodule。专用 LAN 网关端到端、完整私有组网仍需对应实机环境。

## 复现与交付

生产构建 `SWIRL_BUILD_UI_TESTS=OFF`；测试构建 ON。使用 scripts/build-quick-windows.ps1 可构建、检查并部署到新目录。分发含真实固定版本 Mihomo、Qt 动态运行库、恢复助手、脚本运行器、规则及完整许可。待验收便携包/安装包、源码补丁、清单、截图、GIF 与性能原始数据保存在本轮本地交付目录，不把工具、RDC 或安装包提交到源码仓库。

DXGI 方法参考：[DXGI_FRAME_STATISTICS](https://learn.microsoft.com/en-us/windows/win32/api/dxgi/ns-dxgi-dxgi_frame_statistics)、[GetFrameStatistics 及其限制](https://learn.microsoft.com/en-us/windows/win32/api/dxgi/nf-dxgi-idxgiswapchain-getframestatistics)。
