# PR12 原生内核升级：界面基础修复记录

2026-10-15，基于 `8d29650`，没有移除任何页面或功能入口。

## 四角、材质与文字

主窗口、设置和面板取消整个内容区的 MultiEffect 离屏遮罩。原有路径将文字、控件和背景一起渲染到中间纹理再采样；现在仅壁纸进入缓存模糊，窗口轮廓在最终材质 shader 内直接计算，文字保持原生场景图节点。HDR 真正启用时仍保留必要的最终 FP16 色彩转换，不能声称所有硬件路径都零中间纹理。

连续轮廓的四阶距离计算在零值附近做数值保护，材质与外框使用同一曲线和窗口半径。没有引入会截掉半透明抗锯齿像素的二值 Win32 区域。设置的 DNS 底栏取消穿过窗口底角的矩形底色。

壁纸染色权重由 0.72 调到 0.86，浅/深色材质 alpha 为 0.975/0.98，进一步降低背后文字和图标的透出。卡片仍保留活动页认可的 20pt 圆角。D3D11 实际红/蓝后方窗口像素变化随遮盖度下降；验收阈值相应改为较低透射，而非要求维持旧透明程度。

仍使用原样 HarmonyOS Sans、Qt NativeTextRendering、FullHinting 与 Qt 原生 DPI。文字清晰度最终依赖实际屏幕；本轮截图与渲染路径检查不能代替所有字体、GPU、HDR 或实体 DPI 的肉眼验收。

## 主题

SwirlComboBox 上覆盖的 MouseArea 直接调用 popup.open/close，绕过 Qt ComboBox 的原有焦点和输入生命周期，原生弹出窗口的键盘选择未正常提交。移除该覆盖层，让 Qt 负责抓取、选择与关闭。主题写入 Appearance Settings，默认跟随系统，磨砂开关和减少动画设置也持久化。

新增原生 Windows 交互检查：鼠标打开下拉框并选择三个主题、弹出层关闭、键盘 End 选择、系统色板匹配、写入设置，以及另启一个真实应用进程确认深色恢复。全部通过。

## 排版、面板和动画

活动页采用宽网络诊断区、右侧垂直速率区、左侧主趋势、右侧连接与总流量摘要；原有网络、配置、模式、外部 IP、统计及详情入口保留，全部沿用真实数据绑定。

面板保留最近请求、活动连接、DNS、设备、流量、日志六个标签及捕获、MitM、代理控制。顶部导航、搜索与底部操作分行；分组列表真实过滤当前数据。Hosts 明确标为配置，DNS 查询历史标为研发中。清空只在请求/日志上启用，避免其他标签清掉捕获数据。错误继续显示具体故障。

节点详情和请求/端口卡片共享同一进度，并一起移动、展开和返回；无需整表截图。页面、弹窗与展开时长增加 20%，仍支持快速重定向。研发中的静态操作保留并显示状态，已可用的草稿保存、导入、导出及其他实际服务不降级。
