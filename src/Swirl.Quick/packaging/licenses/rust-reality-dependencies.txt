Swirl Core REALITY foundation: dependency license notices

This file preserves license, copyright and notice files distributed in the
crates.io archives for the 29 package versions added by the REALITY foundation.
It includes direct, transitive, target-specific and build dependencies.
The complete locked dependency inventory is core/DEPENDENCIES.json.
The comparison baseline is Swirl commit
df7fd069fafaaf7e767946617d22ae7270d3b09c.

Registry license and notice files were collected without modification using
tools/Collect-RustDependencies.py. Each BEGIN/END FILE block contains the exact
UTF-8 bytes of its named upstream file, followed by one separator newline.
The byte count and SHA-256 identify the upstream content excluding separators.
Package checksums below identify the crate archives pinned by Cargo.lock.
Source revisions come from the archives' .cargo_vcs_info.json files.
License expressions and declared minimum Rust versions reproduce package
metadata; an absent minimum is shown as "not declared".

These notices are included in application bundles by the existing recursive
copy of src/Swirl.Quick/packaging/licenses. Existing component notices remain
in the other files in that directory and in THIRD_PARTY_NOTICES.txt.
