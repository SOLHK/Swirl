Swirl - phase 2 real proxy node test build

This installer includes a real, separate Mihomo engine and manual SOCKS5,
Shadowsocks and Trojan node configuration. Node credentials are protected by
Windows DPAPI. UI simulation data has been removed. Unimplemented network
features remain disabled. The opt-in HTTP capture is real; CONNECT records
metadata without TLS decryption. Windows system proxy can be enabled for a connected node and is restored on
disconnect/exit. TUN, DNS service and route manipulation remain disabled.
