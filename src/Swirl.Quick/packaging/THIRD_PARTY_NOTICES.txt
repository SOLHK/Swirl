Swirl - Qt Quick UI demonstration

This installer contains the Swirl Qt UI. Proxy, DNS, node latency and overview
traffic remain demonstrations. The opt-in loopback HTTP capture service is
real; CONNECT records tunnel metadata without TLS decryption.
The original WPF/.NET network implementation remains in the source repository
and is not started by the Qt UI.
