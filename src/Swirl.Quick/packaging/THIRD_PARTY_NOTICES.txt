Swirl - Rust Core Windows development preview

All proxy node forwarding is implemented by the in-process Swirl Rust Core.
Qt/C++ supplies the UI, configuration/import, operating-system integration and
HTTP debugging/capture tools. No external proxy engine is included or started.
TUN, LAN proxy and gateway forwarding are not yet supported by this Rust product;
unsupported settings are preserved and explicitly rejected, never downgraded.

Clash-compatible subscription parsing is a data-format feature. The proxy
runtime is Swirl Rust Core, with no external core executable or fallback.
