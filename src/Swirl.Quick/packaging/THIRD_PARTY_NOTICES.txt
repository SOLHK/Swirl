Swirl - Windows development preview

This build includes a separate Mihomo engine, real proxy configuration,
optional Windows system proxy/TUN, HTTP capture and scoped HTTPS decryption,
rewrites, local JavaScript execution, configuration overlays and DHCP gateway
control. Credentials and local private keys use Windows DPAPI. Network
takeover and certificate trust require explicit user actions. Unimplemented
features remain unavailable. See the source documentation for limitations.
