Swirl 0.2.17 Windows 测试候选版

Swirl.exe 在进程内使用同源配套的 Rust Core。只安装一个名为 Swirl 的应用，不携带、下载或启动第三方代理内核。保留 Clash/Mihomo 等订阅格式的导入兼容，不提供外部内核回退。

默认安装在当前用户的本地应用目录 Programs/Swirl，可选择已有 Swirl 安装目录升级。安装前请正常退出 Swirl。订阅和用户设置保存在独立用户数据目录，升级不删除它们。安装器不会主动接管系统代理、TUN、路由或 DNS。

导入订阅后，在“节点资源库”按来源浏览、搜索、收藏和测试连接；单击只选中资料，双击或“详情”查看资料。在“策略”页设置出口及分流，在“活动”页使用系统代理开关连接或断开。节点页查看详情或测试连接不会改变正在使用的出口。只有明确支持的协议、传输、TLS、DNS 和规则组合可以启动；不支持的参数会显示原因，不会静默降级为 DIRECT 或弱化 TLS 校验。

本包是当前源代码的测试候选，支持范围、实际执行的测试、失败和待验收项目以同一提交的交付记录为准。编译、隔离本机测试或受控 UI 检查不代表真实供应商节点、Codex Desktop、长期连接或物理多屏验收已经通过。当前 Rust 产品没有已验收的 TUN、LAN 代理或网关数据平面；保存相关设置不代表已经启用。请勿将订阅地址、令牌、密码或节点凭据上传至公开仓库。

在 Windows 已安装应用中选择 Swirl 可卸载。卸载仅删除此安装包的程序文件与快捷方式；用户数据目录及安装目录中另存的文件保留。不要把私人数据放进与程序文件同名的路径。
