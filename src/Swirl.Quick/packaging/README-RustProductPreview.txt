Swirl Windows 测试候选版

Swirl.exe 在进程内使用配套 Rust Core。只安装一个名为 Swirl 的应用，不携带第三方代理内核。

默认安装在当前用户的本地应用目录 Programs/Swirl，可选择已有 Swirl 安装目录升级。安装前请正常退出 Swirl。订阅和用户设置保存在独立用户数据目录，升级不删除它们。安装器不会主动接管系统代理、TUN、路由或 DNS。

导入订阅后，在“节点”页按来源浏览、搜索、收藏和测速；单击只选中资料，双击或“详情”查看资料。在“策略”页选择出口，再点击“连接所选出口”。节点页查看详情或测速不会改变正在使用的出口。只有明确支持的协议、传输、TLS、DNS 和规则组合可以启动；不支持的参数会显示原因，不会静默降级为 DIRECT 或弱化 TLS 校验。

这是节点资源库诊断测试包，已知真实供应商 REALITY 节点和 Codex 联网问题仍未解决，不代表普通可用测试版。国内/专属服务/默认策略的 V2 路由重构、活动页模式菜单和14dp轮廓尚在后续阶段；TUN未实现。支持范围、自动化结果与待验收项目以同一提交的 docs/UI_V2_STAGE3_HANDOFF.md 和原协议矩阵为准。请勿将订阅地址、令牌、密码或节点凭据上传至公开仓库。

在 Windows 已安装应用中选择 Swirl 可卸载。卸载仅删除此安装包的程序文件与快捷方式；用户数据目录及安装目录中另存的文件保留。不要把私人数据放进与程序文件同名的路径。
