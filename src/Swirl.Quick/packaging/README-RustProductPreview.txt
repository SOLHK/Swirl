Swirl Core 应用预览版

这是带正常 Swirl 图形界面的应用，Swirl.exe 在进程内加载 swirl_api.dll 作为 Rust 代理内核。它不是 TEST-SWIRL-NETWORK.cmd 测试工具，也没有打包 Mihomo。

安装目录：D:\Codex\SwirlRust。安装完成后从桌面或开始菜单打开“Swirl Core”。安装器不自动启动程序，也不修改系统代理、TUN、路由或 DNS。现有 Swirl 的程序文件保留。

两个版本使用相同的 Swirl 单实例标识和当前用户数据。使用 Rust 版前，请先正常退出正在运行的旧 Swirl；不要同时运行。旧版如果持有系统代理，退出时可能恢复之前的设置。安装或试用此预览版不要求终止当前正在使用的其他代理。

Rust 会话仅接受已经映射、可以原生执行的节点及网络配置。应用支持全局、规则和直连模式，并在连接时校验所选模式、节点、DNS、规则和策略组；不支持的组合会显示阻止原因，原设置保持不变。请在“节点”选择受支持的节点，手动连接、测试。只有确认节点工作后，才由你决定是否点击“接管系统代理”。安装器不会替你完成这一步。

重要限制：私有订阅节点需要逐条完成原生能力和实际联网验证；其他协议的测试通过不能算作 VLESS/REALITY 节点通过。此阶段的 TUN、网关转发、局域网代理、计费网络模式和部分扩展配置仍未迁移。Rust 模式会拒绝不支持的会话，不回退到其他代理内核。因此它暂时不能作为旧版的等价替换。

若要卸载，在 Windows“已安装的应用”中选择“Swirl Core（预览版）”。卸载程序只删除此版安装的程序文件、生成的诊断文件及快捷方式；目录里若有其他文件，会留下它们，不删除现有 Swirl 程序和用户节点数据。
