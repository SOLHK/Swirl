Swirl Rust Core 应用预览版

这是带正常 Swirl 图形界面的应用，Swirl.exe 在进程内加载 swirl_api.dll 作为 Rust 代理内核。它不是 TEST-SWIRL-NETWORK.cmd 测试工具，也没有打包 Mihomo。

安装目录：D:\Codex\SwirlRust。安装完成后从桌面或开始菜单打开“Swirl Rust Core”。安装器不自动启动程序，也不修改系统代理、TUN、路由或 DNS。现有 Swirl 的程序文件保留。

两个版本使用相同的 Swirl 单实例标识和当前用户数据。使用 Rust 版前，请先正常退出正在运行的旧 Swirl；不要同时运行。旧版如果持有系统代理，退出时可能恢复之前的设置。请保持 Mihomo 可用，不要为了安装此预览版而挂起或结束 Mihomo。

目前只可把已经映射、可以原生执行的节点用于 Rust 会话。请先在左侧“代理 → 策略”选择“全局代理”，再返回“节点”选择受支持的节点，手动连接、测试。旧版 Swirl 保存的“规则判定”不会被安装器偷偷改掉；如果尚未切换，Rust 版会说明原因并保持未连接。只有确认该节点工作后，才由你决定是否点击“接管系统代理”。安装器不会替你完成这一步。

重要限制：现有私有订阅中的 59 条 VLESS/REALITY 节点仍为 0/59 原生可执行资格；Shadowsocks 测试通过不能算作这些节点通过。此阶段的 TUN、LAN、智能规则库和部分完整配置也没有迁移。Rust 模式会拒绝不支持的会话，不回退到 Mihomo。因此它暂时不能与 Mihomo 内核版等价替换。

若要卸载，在 Windows“已安装的应用”中选择“Swirl Rust Core（预览版）”。卸载程序只删除此版安装的程序文件、生成的诊断文件及快捷方式；目录里若有其他文件，会留下它们，不删除现有 Swirl 程序和用户节点数据。
