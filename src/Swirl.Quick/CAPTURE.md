# 真实 HTTP 抓包

1. 在左栏打开“抓包”。默认尚未监听。
2. 选择空闲本机端口，点击“开始抓包”；端口 0 可自动选择空闲端口。
3. 将测试浏览器或工具的 HTTP/HTTPS 代理设置为页面显示的 `127.0.0.1:端口`。
4. 发起请求，点击会话查看请求/响应，筛选或导出 HAR。
5. 点击“停止抓包”，并恢复测试应用原代理设置。

命令行验证示例（仅对用户自己的测试目标）：

```powershell
curl.exe --proxy http://127.0.0.1:8899 http://你的测试地址/
```

这是实际转发的 HTTP 会话捕获，并非演示记录。HTTPS CONNECT 支持真实 TCP 隧道转发和字节统计；TLS 内容没有解密。
本功能不修改 Windows 系统代理、不安装驱动、不写证书信任、不开启 TUN。总览的代理演示开关与本页独立。
它不是全网卡 PCAP，也不是完整 Surge 抓包/断点/MITM 功能。

限制：64 个活动连接、1000 条历史；HTTP 上传正文 1 MiB、响应 2 MiB；预览/导出正文 64 KiB；20 秒 HTTP 上游超时；不支持分块上传和 HTTP Upgrade。HTTP 字节计数是正文长度，CONNECT 字节计数是隧道载荷长度。
HAR 中 `_swirl` 字段标注隧道、未解密和预览截断状态。认证、Cookie 和常见 URL 密钥在记录中隐藏，正文可能仍包含用户数据。
记录只保存在本次进程内存中，除非用户主动选择导出文件。

## 验证

测试构建使用 `-DSWIRL_BUILD_UI_TESTS=ON`。执行 `Swirl.exe --capture-self-test`。
集成测试使用真正的本机 TCP/HTTP 服务和显式代理客户端，验证 GET、POST、认证转发与记录脱敏、原始 CONNECT 载荷、拒绝负长度/分块上传/自循环、HAR 和停止监听。不会访问外网或改变系统网络配置。

`Swirl.exe --interaction-test` 还会通过实际按钮验证抓包页的开始/停止监听。
生产安装包不包含测试 harness；抓包服务在正常启动时保持关闭。
